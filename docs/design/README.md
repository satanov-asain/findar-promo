# FINDAR Design Memory

Эта папка фиксирует дизайн-стандарт проекта FINDAR. Перед любыми новыми UI-правками сначала читать:

1. `00-design-research.md` - источники и выводы из внешних дизайн-систем.
2. `01-findar-design-direction.md` - визуальное направление именно для FINDAR.
3. `02-motion-and-animation.md` - правила анимации, скролла и микровзаимодействий.
4. `03-skeuomorphism-neumorphism-notes.md` - как применять физичные стили без дешевого эффекта.
5. `04-implementation-checklist.md` - чеклист перед сдачей любой визуальной правки.

Главный принцип: FINDAR должен выглядеть как серьезный industrial / certification / engineering продукт. Эффекты допустимы только если они усиливают доверие, читаемость, навигацию или ощущение точной технологии.
