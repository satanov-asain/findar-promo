# CODEX Instructions For FINDAR

This project has a design memory. Before changing UI, layout, animation, header, colors, cards, hero, CTA, or responsive behavior, read `.codex/project-memory.md` and all files referenced by `.codex/findar-design.config.json`.

Do not treat FINDAR as a generic landing page. The target is a high-class industrial testing/certification website.

Mandatory rule for visual work:

- explain the design intent before editing;
- implement with restrained industrial style;
- verify in browser on desktop and mobile;
- respect `prefers-reduced-motion`;
- avoid decorative effects that do not improve comprehension, confidence, or conversion.
